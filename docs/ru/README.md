# Документация go-cli

- [Команды](commands.md): регистрация дерева, наследование flags, aliases, wrappers.
- [Flags и positional args](arguments.md): объявления, типы, источники значений и проверки.
- [Запуск и ошибки](runtime.md): `Run`, `Main`, context, потоки, ошибки и повторные вызовы.
- [Help и completion](help-completion.md): встроенная справка, `Info()` и API для shell integration.
- [Справочник API](api.md): краткая карта публичных методов и ограничений.

Для примеров нужен Go 1.27. Import path библиотеки: `github.com/kamilov/go-cli`, имя пакета: `cli`.
